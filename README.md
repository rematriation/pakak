# Pakak

***pakak*** definition ([inupiaqonline.com](https://inupiaqonline.com/pakak(-))):

- (i) to rummage through things looking for something, often surreptitiously (NALUNAIŊARUQ SURAĠAQTI)
- (i) to get into mischief (NALUNAIŊARUQ SURAĠAQTI)
- mischief maker (ATIQAUSIQ)

App to conduct sustainable and engaging community-led digital archiving via mobile texting campaign services.
