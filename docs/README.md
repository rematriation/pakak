## Twilio

Nalukataq uses [Twilio](https://twilio.com)'s services to create reliable sending and receiving of SMS/MMS messages.

[Read more](./twilio.md) about our setup and configuration.

## Amazon Web Services

Nalukataq uses "***serverless***" and DynamoDB services of [Amazon Web Services](https://aws.amazon.com) (AWS) to store the *Users* table of our data model that monitors and tracks users who are either subscribed or unsubscribed to Nalukataq.

[Read more](./aws.md) about our setup and configuration.

## MongoDB

Nalukataq uses [MongoDB](https://mongodb.com) to store the *UserProfile* and *ImageBasedSubmission* tables of our data model.

[Read more](./mongodb.md) about our setup and configuration.
